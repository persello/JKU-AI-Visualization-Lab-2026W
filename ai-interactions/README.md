# AI interactions

Records of the AI-aided pair's use of generative AI, as the assignment asks. One file per session or topic, in the folder of the phase:

- `phase1/`: Phase I (midpoint)
- `phase2/`: Phase II (final)
- `setup/`: repository and training setup, before Phase I. No analysis was done there.

Name files `YYYY-MM-DD-topic.md` and start from `TEMPLATE.md`. Keep the important prompts and what happened to each suggestion (accepted, changed, or rejected, and why).
